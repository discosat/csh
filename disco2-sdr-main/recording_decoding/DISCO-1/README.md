# DISCO 1 Legacy Decoding Files

This folder contains the working example of a Ping decoding from DISCO-1. It contains both an RX and TX files, and has been tested in the DASYA Lab with the hardware mentioned in the documentation.

This file has been modified to make it work for our set-up. The documentation for DISCO-1 was made by Thomas Hansen and can be found in [the disco_gnuradio repository](https://github.com/discosat/disco_gnuradio).

There is no support for this decoding, the files are mostly here for education purposes and to have a streamlined working example.

Since most of the decoding pipeline is shared across DISCO-1 and DISCO-2, any questions are most likely answered by the more in-depth documentation that can be found in the DISCO-2 folder.

To download the PING recording `.raw` file needed for the GNURadio file block, you can visit the original repo or [follow this direct link](https://github.com/discosat/disco_gnuradio/blob/main/ping_recording_disco1_to_gs.raw).
