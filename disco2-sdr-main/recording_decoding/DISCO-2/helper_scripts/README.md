## `generate_doppler.py`

This scripts generates a `.txt` file that can be used in the [`Doppler Correction`](https://destevez.net/2022/07/real-time-doppler-correction-with-gnu-radio/) GNURadio bloc.

It was mainly used when trying to decode old scripts, where I didn't have access to their respective TLE.

In the `Doppler Correction` block, you have to set the following fields:
- **File**: The path to the newly written `.txt` file
- **Start Time**: The first timestamp
