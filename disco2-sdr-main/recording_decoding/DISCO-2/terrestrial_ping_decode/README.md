# DISCO-2 Terrestrial Ping Recording

This folder contains the earliest succesful decoding of a DISCO-2 signal. This PING was recorded in Aarhus University prior to DISCO-2 launch.

It is nearly unmodified from the working DISCO-1 decoding pipeline, which was also presumably a terrestrial recording.
